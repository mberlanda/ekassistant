# Support Escalation Macros

## When to escalate to engineering

Escalate a ticket to engineering only after confirming the issue is not
covered by an existing macro and reproducing it at least once. Do not
escalate on a single unconfirmed customer report.

## Priority definitions

A ticket is P1 if the customer cannot log in or is losing data. It is P2
if a core feature is broken but a workaround exists. Everything else is
P3 unless a customer explicitly requests expedited handling in writing.

## Refund macro

Refunds under $50 can be issued directly by any support agent using the
standard refund macro. Refunds over $50 require a team lead's approval
logged in the ticket before the macro is used.
