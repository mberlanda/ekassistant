Engineering Onboarding

Repository access

New engineers are added to the core repository group on their first day, not before, since provisioning is tied to the signed equipment agreement.

Local environment setup

Use the pinned interpreter version in each repository's version file rather than whatever is already installed system-wide, to avoid dependency drift between engineers.

First week expectations

Ship one small, reviewed pull request in the first week. It does not need to be significant in scope - the goal is exercising the review and deploy process end to end, not the size of the change.
